# 💚 นับตัง (NABTANG) — ผู้ช่วยการเงินและภาษีในไลน์

แอพเดียว 2 โหมด เปิดใช้ในไลน์ผ่าน LIFF (หรือเบราว์เซอร์ธรรมดา):

1. **โหมดกระเป๋า 👛** — จดรายรับรายจ่ายเสร็จใน 3 แตะ แบ่งหมวดหมู่
   สรุปยอดรายวัน/รายเดือน กราฟสัดส่วน เทียบเดือนก่อน ออกรายงาน CSV
2. **โหมดภาษี 🧮** — ประมาณการภาษี ภ.ง.ด.91 แบบตอบคำถามทีละข้อภาษาคน
   พร้อมแนะนำตัวช่วยลดหย่อน (RMF · Thai ESG · ประกันต่าง ๆ) เรียงตามความคุ้ม
   มีแถบทดลอง "ถ้าลงทุนเพิ่ม X จะประหยัดภาษีเท่าไหร่" และข้อดี-ข้อควรระวังครบทุกตัว

ออกแบบสำหรับคน**ไม่เข้าใจภาษี ไม่ชอบตัวเลข** — ทุกศัพท์ภาษีมีคำอธิบายภาษาคนกำกับ

## ไฟล์ในโปรเจกต์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้า showcase / หน้าขายของ |
| `app.html` | ตัวแอพจริง (ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร) |
| `SETUP.md` | คู่มือติดตั้งลง LINE OA + LIFF และวิธีเอาไปเปิดขาย ทีละขั้น |
| `CLAUDE.md` / `SPEC.md` / `TASKS.md` | พิมพ์เขียวระบบสำหรับพัฒนาต่อ |

## เริ่มใช้เร็วที่สุด

เปิดไฟล์ `app.html` ในเบราว์เซอร์ได้เลย (ดับเบิลคลิกก็ได้) — ข้อมูลเก็บในเครื่องผู้ใช้
อยากให้เปิด "ในไลน์" ได้จริง ทำตาม `SETUP.md` (ประมาณ 30 นาที ฟรีทั้งหมด)

## หมายเหตุสำคัญ

- ผลภาษีเป็น**การประมาณการเบื้องต้น** อ้างอิงเกณฑ์ปีภาษี 2568 —
  ก่อนยื่นจริงโปรดตรวจกับกรมสรรพากร (rd.go.th)
- ต้นปีภาษีใหม่ให้อัปเดตตาราง `const TAX = {...}` ใน `app.html` (จุดเดียว)
- ข้อมูลเก็บใน localStorage ของเครื่องผู้ใช้ — แนะนำออก CSV สำรองเป็นระยะ
  (เวอร์ชันขายหลายคนแบบฐานข้อมูลกลาง ดูหัวข้อ "ขั้นถัดไป" ใน SPEC.md)
